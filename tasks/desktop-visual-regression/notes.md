# Visual regression snapshots light and dark and 10k-line first paint ≤ 500 ms (plan M7, plan §7)

Plan M7 acceptance: "Visual regression snapshots for light and dark themes. Startup to first
paint of a 10 k-line file ≤ 500 ms on the CI runner."

## Snapshots are goldens, updated deliberately

Playwright visual comparison via `toHaveScreenshot`
(https://playwright.dev/docs/test-snapshots), one project per theme (light and dark), against a
10 k-line fixture. Cover the surfaces that change with theme: main view (with `id:` hidden and
decorations visible), popover, detail view, and the conflict sheet. Goldens are committed and only
regenerated by an explicit update, never silently — the plan requires a CI regeneration-diff step
only for the Lezer grammar, not for snapshots.

## First paint of 10 k lines is a measurement, not a hope

CM6 renders a virtualized viewport, so the risk is not drawing 10 k DOM lines — it is eagerly
tokenizing or decorating all 10 k. Bound decorations to the visible viewport range so a 10 k-line
file costs the visible window only. The perf test loads the 10 k-line fixture, records time to
first paint, and asserts ≤ 500 ms on the CI runner (Playwright timing, same machine as the
snapshots so the number is reproducible).

## Acceptance

- Light and dark goldens committed for main view, popover, detail, conflict sheet.
- Perf test: 10 k-line first paint ≤ 500 ms on the CI runner, asserted.
